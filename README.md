# Beyond the Veil

Mod de terror psicológico para Minecraft Java Edition 1.21.1, Fabric e Java 21.

> Estado inicial: estrutura do projeto em implantação. Nenhuma funcionalidade é considerada concluída sem compilação e testes verificáveis.

## Requisitos

- Minecraft Java Edition 1.21.1
- Java 21
- Fabric Loader e Fabric API compatíveis

## Desenvolvimento

O build é baseado em Gradle e Fabric Loom. No GitHub, a workflow de CI executa a compilação e os testes automatizados. Para compilar localmente, use uma instalação Gradle compatível com o projeto e execute `gradle build`.

## Idiomas

Português do Brasil (`pt_br`) e inglês (`en_us`).

## Segurança e privacidade

O mod não deve acessar arquivos pessoais, executar processos externos, enviar dados pela rede ou implementar telemetria. Dados próprios devem permanecer nos diretórios de configuração e dados do mundo do Minecraft.
